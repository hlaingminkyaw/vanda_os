# Project Rules & Guidelines

1. **Documents Location**: Always put all documentation, specifications, architecture assets, diagrams, and reference guides inside the `docs/` folder. Never leave loose documentation files in the repository root.
2. **README Updates**: Whenever updating or modifying the codebase, review and update `README.md` when necessary to reflect new features, architectural changes, scripts, or operational guidelines.
3. **Feature Task Creation**: When adding new features, always create a Backlog.md task first (using the Backlog CLI, e.g., `backlog task create "<Title>"`) before implementing the feature, defining clear acceptance criteria and scope.
4. **Move Completed Tasks**: Whenever a task is marked as Done/completed, always move the task file into the suitable completed folder (`backlog/completed/`) to keep active task directories organized.
